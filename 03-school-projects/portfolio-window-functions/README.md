# Portfolio: Advanced SQL Window Functions & JOINs

## Overview
A professional portfolio demonstrating mastery of analytical SQL through real-world business scenarios. Each scenario is a complete case study with schema design, queries, and business insights.

## Why This Portfolio

- **Proves** understanding of both syntax AND business context
